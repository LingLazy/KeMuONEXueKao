## 项目简介

本项目是一个面向机动车驾驶证科目一考试的全功能在线学习网页，覆盖**完整 1964 道官方题库**、**76 条精选速记口诀**、**24 个精细分类**与**371 道图像题**，提供关键词智能高亮、口诀即时提示、分类速练、双主题切换等完善功能，助力考生高效备考。

数据严格依据公安部令第 163 号《道路交通安全违法行为记分管理办法》（2022 年 4 月 1 日施行，现行有效）与 GB 5768.2-2022《道路交通标志和标线》等最新法规标准。

## 功能特性

### 四大视图 · 一站式学习

- **主页**：Hero 数据概览、核心功能入口、热门分类速达、个人进度统计
- **题库练习**：1964 道题目完整练习，左侧分类侧栏 + 右侧答题主区
- **口诀总览**：76 条速记口诀按分类筛选查阅，每条附解释与适用场景
- **分类导航**：24 个分类可视化卡片，点击即进入对应分类题目练习

### 智能学习辅助

- **关键词高亮**：题干、选项、解析中自动高亮关键词，危险词红色、数字类蓝色、其余主色
- **口诀即时提示**：答题后根据题目分类自动匹配相关口诀，最多展示 3 条
- **详细解析**：每题附完整解析，关键词同步高亮
- **图像题支持**：371 道图像题配套真实图片，控制高度确保一屏可见

### 完善交互体验

- **双主题切换**：浅色 / 深色双主题，薄荷青 + 珊瑚橙清新配色，localStorage 记忆偏好
- **键盘快捷键**：`←` `→` 翻页，`1` `2` `3` `4` 或 `A` `B` `C` `D` 选择选项
- **题号跳转**：输入题号快速跳转至任意题目
- **搜索筛选**：按题干、解析、标签全文搜索
- **乱序练习**：一键开启乱序，打乱题目顺序强化记忆
- **进度记忆**：答题进度、正确率、主题偏好全程 localStorage 持久化
- **URL 路由**：四视图 hash 路由，支持分享直达指定视图

### 质感 UI 设计

- **清新配色**：薄荷青主色 (#0d9488) + 珊瑚橙强调色 (#f97316)
- **层次布局**：主页 Hero + Features + Hot Categories 三段式结构，避免单一流式滚动
- **细腻动效**：卡片悬浮微动效、进度条流光、视图进入动画、按钮态脉冲指示
- **毛玻璃导航**：`backdrop-filter: blur(20px) saturate(180%)` 滚动时增强
- **响应式布局**：三档断点 (1100px / 900px / 600px) 适配桌面、平板、移动端
- **按钮状态明显**：乱序按钮激活态主色填充 + 脉冲指示点，主题切换图标旋转动效

## 技术栈

- **纯静态部署**：HTML5 + CSS3 + 原生 JavaScript（无框架、无构建工具）
- **SPA 架构**：四视图 hash 路由单页应用
- **CSS 设计令牌**：完整设计令牌系统（背景层次、文字层次、状态色、阴影、圆角、动效曲线）
- **CSS 变量主题**：`[data-theme]` 属性切换，CSS 变量级联更新全站样式
- **数据驱动**：题库、口诀、分类数据独立为 `js/data.js`（约 2.5MB）
- **部署平台**：GitHub Pages

## 本地运行

### 方式一：Python 启动

```bash
# 进入项目根目录
cd KeMuONEXueKao

# 启动本地服务器（Python 3）
python -m http.server 8000

# 浏览器访问
# http://localhost:8000
```

直接用浏览器打开 `index.html` 即可（部分浏览器功能可能受限，推荐使用本地服务器方式）。

## 部署到 GitHub Pages

本项目已部署至 GitHub Pages，在线访问：<https://fanquanpp.github.io/KeMuONEXueKao/>

如需自行部署：

1. Fork 本仓库至你的 GitHub 账户
2. 进入仓库 **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`
4. **Branch** 选择 `main` / `(root)`，点击 **Save**
5. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/KeMuONEXueKao/`
