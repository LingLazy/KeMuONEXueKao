# 科目一教考在线学习 (KeMuONEXueKao)

2026年7月最新版机动车驾驶证科目一在线学习网页项目。依据公安部令第163号《道路交通安全违法行为记分管理办法》（2022年4月1日施行，现行有效）。

## 项目特点

- 纯静态网页（HTML/CSS/JS），无需后端，可直接部署到 GitHub Pages
- 现代化 UI 设计，响应式布局，移动端友好
- SPA 单页应用，通过顶部导航切换模块
- 所有内容基于 2026 年 7 月最新法规

## 功能模块

| 模块 | 说明 |
|------|------|
| 首页 | 项目概览与功能导航，统计数据展示 |
| 口诀背记 | 12 大类速记口诀，支持分类筛选 |
| 题目练习 | 60 道题（判断题 30 + 单选题 30），分类练习，即时解析 |
| 模拟考试 | 100 题随机抽题，90 分及格，错题回顾 |
| 记分管理 | 12/9/6/3/1 五档完整记分规则与口诀 |
| 标志识别 | 交通标志、道路标线、交警手势信号图解 |
| 2026新变化 | 最新法规变化要点与新能源知识考点 |

## 本地运行

在项目根目录执行：

```bash
python -m http.server 8000
```

浏览器访问 `http://localhost:8000` 即可。

## 部署到 GitHub Pages

1. 将项目推送到 GitHub 仓库
2. 在仓库 Settings > Pages 中选择 main 分支
3. 访问生成的 GitHub Pages URL 即可

## 法规依据

- 公安部令第163号《道路交通安全违法行为记分管理办法》（2022年4月1日施行）
- GB5768.2-2022《道路交通标志和标线 第2部分：道路交通标志》（2022年10月1日实施）
- 高速限速全国统一五档标准：120/100/80/60/40
